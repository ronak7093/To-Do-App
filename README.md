# 📝 React To-Do List App

A simple and elegant **To-Do List** built with **React.js** and styled with **CSS**. It allows users to add, edit, delete, and manage their tasks efficiently. Toast notifications are used for smooth user feedback.

---

## 🚀 Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 🛎️ Beautiful toast notifications using `react-toastify`
- 💅 Clean and responsive UI

---

## 🛠️ Tech Stack

- **React.js** (with Hooks like `useState`)
- **CSS** (for custom styling)
- **React Icons** (`react-icons/fa`)
- **React Toastify** (`react-toastify`)
